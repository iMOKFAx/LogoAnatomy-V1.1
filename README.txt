LOGO ANATOMY v1.1 - see how a logo is built, then make it cleaner
Made by Mohamed Mostafa

Works with Illustrator 2022 or newer (Windows and Mac).

Open "Logo Anatomy - Guide.html" in any browser to see how it works and try it on a sample or your own SVG.

INSTALL
  Windows : close Illustrator, double-click Install-Windows.bat
  Mac     : close Illustrator, right-click Install-Mac.command > Open
            (if macOS blocks it: System Settings > Privacy & Security > Open Anyway)
  Then open Illustrator:  Window > Extensions > Logo Anatomy

HOW IT WORKS
  1. Select your logo (Selection tool, V) and press Make Guide.
  2. The guide is drawn on a locked layer called "Logo Anatomy" on top: construction circles,
     points that line up, angles, mirror axis, box and clear space. Turn each kind on or off in the panel.
  3. Improvements: Fix changes only that spot, Keep it hides a note you meant.
     Click a note to select that point in Illustrator. Ctrl+Z (Cmd+Z) or Undo fixes brings it back.

BEFORE YOU START
  - Text must be outlined: Type > Create Outlines.
  - Effects / Appearance strokes: Object > Expand Appearance.
  - Images must be traced first (Image Trace > Expand).
  - The logo's layer must not be locked if you want to use Fix.

The installer turns on "PlayerDebugMode" so Illustrator loads this panel (standard for panels
installed without Adobe Exchange). Nothing else is changed.
